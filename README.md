---

## 🌟 Key Features

- **Trending Dark Glassmorphism**: Translucent frosted panels (`backdrop-filter: blur(18px)`), refined borders, and glowing accents.
- **Aurora Canvas Background**: Pure HTML5 canvas radial gradient animation with organic motion.
- **Interactive Dark / Light Mode Toggle**: Smoothly switches between deep dark space theme and frosted daylight theme, persisted with `localStorage`.
- **Interactive Project Filtering**: Instant client-side filter tabs (**All**, **GenAI**, **AI / ML**, **Full Stack**, **Analytics**) for all 9 featured projects.
- **Mouse Spotlight Glow**: Dynamic cursor-following light cone illuminates cards upon interaction.
- **Direct Resume Integration**: Dedicated CTA buttons pointing directly to Meghana's Google Drive Resume in a new tab.
- **Client-Side Validated Contact Form**: Real-time validation states for required fields with instant success feedback.
- **Fully Responsive & Accessible**: Mobile-first design, adaptive sticky navigation pill, accessible hamburger drawer, and `prefers-reduced-motion` compliance.

## 🚀 Quick Deployment Options

### 1. GitHub Pages (Recommended)
1. Go to repository **Settings** → **Pages**.
2. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`.
4. Click **Save**. Your site will be live at:
   `https://meghanara123456.github.io/my-portfolio/`

### 2. Netlify Drop (Instant / No Account Needed)
1. Navigate to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop this folder or `index.html` directly into the drop zone.
3. Your site is live instantly on a secure HTTPS URL.

### 3. Vercel
1. Import this repository into Vercel.
2. Leave Build Command and Output Directory blank.
3. Click **Deploy**.
